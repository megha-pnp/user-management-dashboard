# User Management Dashboard

A single-page CRUD practice project built with HTML, CSS, and vanilla JavaScript.

## Features
- GET: Load and display users from JSONPlaceholder.
- POST: Add a simulated user.
- PUT: Update the first user's email.
- DELETE: Remove a user from the displayed list.
- Loading and error messages using async/await, try/catch, and finally.

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a browser.
3. Use the buttons to test the CRUD operations.
4. Open Chrome DevTools (F12) > Network > Fetch/XHR to inspect requests.

## API note
JSONPlaceholder simulates POST, PUT, and DELETE responses. Changes are only reflected in this page's local UI and are not permanently stored on the server. Refreshing restores the original API data.
